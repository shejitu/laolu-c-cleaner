# 老卢系统盘清理

**免费 · 开源 · 完全本地 · 无广告**

一款简单易用的 Windows 系统盘（C 盘）清理工具：一键扫描清理垃圾文件、分析 C 盘大文件、清理使用痕迹。

</div>

> 本项目按 [craft-anything](https://github.com/storytold/craft-anything) 的净室方法重写自某闭源清理软件的**公开功能行为**（见 [docs/净室研究记录.md](docs/净室研究记录.md)）：只研究功能、不接触原代码，全部代码为原创。

## ✨ 功能

| 页签 | 功能 |
|------|------|
| 🧹 垃圾清理 | 一键扫描系统/用户临时文件、缩略图缓存、DirectX 缓存、更新下载残留、崩溃转储、浏览器缓存等已知安全位置，展示体积、勾选后清理 |
| 📊 C盘瘦身 | 列出系统盘 ≥100 MB 的最大目录与文件，帮你找到占空间的大头（只列出，删不删由你判断） |
| 🕵️ 隐私清理 | 清除「最近使用文档」记录、清空回收站 |
| 💻 系统信息 | 系统盘剩余空间、内存占用实时查看 |

## 🛡️ 安全承诺

- **白名单删除**：清理目标全部是公认安全的缓存/临时位置，绝不碰用户文档、桌面、下载。
- **先展示后删除**：扫描结果逐项列出，你看清楚、勾选确认后才删。
- **完全本地**：无任何网络请求、无广告、无推广。
- **开源可查**：MIT 协议，删了什么代码一目了然。

## ⚡ 下载使用

前往 [Releases](../../releases) 下载 `老卢系统盘清理.exe`（绿色单文件，免安装），双击即用。

要求：Windows 10 / 11。

### 从源码运行

```bash
python src/laolu_cleaner.py        # 需要 Python 3.9+（标准库，无第三方依赖）
python test/test_core.py           # 核心逻辑自测
```

### 自己打包 exe

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name 老卢系统盘清理 src/laolu_cleaner.py
```

（GitHub Actions 会在每次推 tag 时自动构建 exe 并发布到 Releases。）
