## 原品：ChenXi996/c-cleaner（极智C盘清理）
闭源 Windows 桌面软件，本仓库仅依据其 README 公开描述的功能行为做净室重写。
不复制任何代码、图标、文案、截图；不使用原品牌名（CPanx / 极智）。

## 功能行为清单（来自公开 README）
| # | 原品行为 | 本项目对应 |
|---|---------|-----------|
| 1 | 一键清理 C 盘垃圾（智能扫描清理系统垃圾） | 垃圾清理：扫描临时目录、回收站、系统缓存、浏览器缓存等已知垃圾位置，展示分类体积，勾选后删除 |
| 2 | C 盘瘦身、系统扩容 | 大文件分析：列出 C 盘最大文件/目录，提示可安全转移的项 |
| 3 | 清理隐私痕迹 | 隐私清理：最近文档记录、运行记录、回收站、浏览器浏览记录入口（注册表 Recent 等已知位置） |
| 4 | 加速内存 | 系统信息页显示内存占用（v1.0 只读展示，不做激进内存释放——乱释放反而伤性能，属于我们自己的设计判断） |
| 5 | 文件碎片整理 | 不复刻：Windows 自带 defrag 已足够，重复造轮子无收益（设计取舍，记录在案） |
| 6 | 热搜/数据恢复/截图录屏等百宝箱 | 不复刻：与"系统盘清理"主题无关 |

## 我们的设计原则（与原品不同处，明确声明）
- **安全第一**：所有删除目标都在白名单内（系统临时目录、缓存目录等公认安全项），绝不碰用户文档；扫描结果先展示、用户勾选确认后才删。
- **完全本地**：无网络请求、无广告、无推广模块。
- **免费开源**：MIT。
- 目标平台 Windows 10/11（开发验证在路径抽象层做，核心逻辑可跨平台测试）。

## 交付形态
- 纯 Python + tkinter（标准库界面，零第三方依赖），PyInstaller 打包单文件 exe。
- GitHub Actions 在 windows-latest 自动构建 exe 发布。
